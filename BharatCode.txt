OSSPilot
A terminal-native AI assistant for discovering open-source projects, understanding issues, and organising contribution workflows.

WHAT IT DOES
- Discovers open-source repositories and their contribution opportunities through the GitHub API.
- Researches a specific issue: project health, issue intelligence, contribution accessibility and a suitability score.
- Inspects a repository you have open (languages, layout, tests, conventions, recent history).
- Plans a contribution scoped to one issue, then runs the implementation inside an isolated Git worktree with human approval at every gate.
- Verifies changes (tests, lint, diff) before anything is proposed for review.

BHARATCODE USAGE
OSSPilot's intelligence service runs on the BharatCode model API: repository health scoring,
issue intelligence, contribution suitability assessment and repository inspection summaries
are generated by a BharatCode model (default endpoint https://bharatcode.ai/api/model/v1,
default model qwen-3.8-27b, configurable via ~/.osspilot/config/config.json).

The provider is behind a small registry, so OpenAI and Anthropic can be substituted with an
API key, and the implementation stage delegates to OpenCode, which uses whatever provider the
user has configured.
